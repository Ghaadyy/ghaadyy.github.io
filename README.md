## Getting Started

### Running Locally (Debug & Preview)

1. Install the **Hugo** CLI by following the official instructions [here](https://gohugo.io/installation/).

2. Clone your forked repository to your local machine.

3. Run the following command in the root directory of the repository:

   ```bash
   hugo server -D
   ```

4. Browse to `http://localhost:1313` (or the URL shown in your terminal) to preview the website.
