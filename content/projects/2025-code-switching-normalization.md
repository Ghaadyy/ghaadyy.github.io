description: "Lebanon is a linguistically diverse country where Arabic, English, and French coexist in education, media, and daily communication. As a result, written and spoken communication frequently mixes all three languages, a phenomenon known as code-switching. While natural to Lebanese speakers, such mixed-language text poses challenges to NLP systems, which are typically trained on monolingual data. Existing translation, summarization, and sentiment models often fail to process this hybrid input correctly. This project proposes the development of a deep learning model that automatically normalizes Arabic–English–French code-switched text into a coherent monolingual output (Arabic or English). The system will leverage multilingual architectures to learn language boundaries, resolve transliteration, and produce grammatically correct normalized text that reflects the intended meaning. The outcome will contribute to Arabic NLP research and support more inclusive language technologies for Lebanon’s trilingual environment."
